## 2026-09-01 — WP1 第一、二轮高精度检索完成

### 首轮关键发现

1. **System Dynamics / Simulation 用于技术预见不是研究空白。** 2012 年已有 Delphi + System Dynamics 两阶段 technology foresight；2016 年已有通过 SD simulation 生成 technology development paths 的研究。
2. **Agent-based technology forecasting 不是研究空白。** 2009 年已有 Brownian agent-based technology forecasting。
3. **经验数据校准/数据驱动 ABM 不是研究空白。** 2009 年已有经验数据校准并用独立数据验证的创新扩散 ABM；2016 年已有 ABM 参数估计用于预测；2017 年已有数据驱动自动生成创新扩散 ABM 并做干预实验。
4. **动态图/GNN/异构图做 Technology Opportunity Discovery 不是研究空白。** 2025–2026 年已有 RGNN、DynGNN、DGNN、Heterogeneous GNN、LSTM+GCN 等技术机会预测研究。
5. **多源数据 + 弱信号技术预见不是研究空白。** 2026 年已有专利、临床、新闻、论文四源数据的弱信号新兴主题识别，也已有 ML + weak signal 的完全数据驱动 technology foresight。
6. **LLM 多智能体做科研方向/idea forecasting 不是研究空白。** 2025 年 `Academic Simulacra` 已使用 scholar agents 基于历史发表记录预测 2024 年研究 idea。

### 对创新表述的即时修订

以下表述从现在起禁止作为论文创新主张：

- 首次将 simulation/system dynamics 用于技术预见；
- 首次将 ABM 用于技术预测；
- 首次使用经验数据校准 ABM；
- 首次使用动态图/异构图做技术机会发现；
- 首次使用多源数据和弱信号做技术预见；
- 首次使用 LLM 多智能体做未来研究方向预测。

### 当前保留的候选方法缺口

A. **多源技术状态建模**：不是简单把多源文档混合聚类，而是把 Science、Patent、Open Source、Vulnerability Demand 分别作为技术状态的不同机制证据。

B. **Cross-source Lead-Lag**：显式学习 Paper→GitHub、GitHub→Patent、Vulnerability→Research/Engineering 等动态时滞。

C. **Learned Dynamics → Intervenable Simulation**：把历史学习到的技术状态转移和技术相互作用转化为可施加 shock 的 Monte Carlo forward simulation，而非仅一次性预测。

D. **严格 Historical Reconstruction**：采用 temporal cutoff / rolling-origin backtesting，验证模型停留在历史时间点时能否重建后来真实发生的技术增长、Emergence 与 Convergence。

E. **Accuracy + Calibration + Uncertainty + Counterfactual**：在同一技术预见框架中同时评价预测准确性、排序、概率校准、不确定性与反事实情景敏感度。

F. **Computational Simulation + Agentic Stress Test**：主模型使用可回测量化推演，LLM Agent 仅补充制度、组织、采用障碍和极端事件压力测试。

### 当前方法定位调整

ECDS-TF 的创新方向由“首次引入某个算法组件”调整为：

> **一种组合型方法与验证范式：将多源科技情报映射为可解释技术状态，通过历史数据学习跨源时滞与技术相互作用，将 learned dynamics 转化为可干预概率动态推演，并用严格历史回测验证技术预见有效性。**

该定位仍为候选，需要后续检索确认是否存在高度同构工作。

## 2026-09-01 — WP1 第三轮定向 Gap 查重完成

**状态：IN_PROGRESS**

### 本轮检索范围

围绕上一轮保留的 7 个候选缺口进行了专项检索：

1. Science–Technology / paper–patent lead-lag；
2. GitHub / open-source 作为技术创新和工程扩散信号；
3. CVE/CWE/vulnerability pressure 作为需求牵引变量；

5. probabilistic forecasting / calibration / uncertainty；
6. learned graph dynamics + scenario intervention / counterfactual；
7. LLM agent forecasting 的 temporal leakage 与知识截止控制。

### 新增关键发现

1. **Lead-Lag 独立创新被进一步否定。** 2024 年已有 science–technology dynamic structure-coupling + time-lag cross-correlation 用于技术机会发现；2026 年已有 S&T knowledge lag + temporal co-occurrence network + dual-stream attention，并完成 1/3/5-step technology-transfer opportunity prediction。
2. **论文+专利+GitHub 三源融合独立创新被否定。** 2026 年已出现 Publications + Patents + GitHub 的 emerging-technology topic identification，并明确将 GitHub 解释为更敏感的早期工程/实现信号。
3. **GitHub 用于未来技术景观预测已有直接先例。** 2026 年已有基于 GitHub repository network、library coupling、GCN link prediction 的 AI technology landscape prediction。
4. **论文—GitHub 时序关系已有实证基础。** 2023 年研究把 Papers with Code、学术图谱和 GitHub API 连接起来，分析代码仓库出现后论文扩散变化；2026 年又有 paper-with-code diffusion 的大样本研究。
5. **Historical validation 不是空白。** 2019 年已有 expert foresight 与五年后 realized outcomes 的直接比较；2020 年 emerging-technology DL 使用 2000–2016 预测 2017 并用真实 2017 结果验证；近期又出现 rolling-origin technology forecasting 尝试。
6. **Probabilistic technology forecasting 不是空白。** 1991 年已有 semi-Markov probabilistic technology development simulation；2003 年技术预测综述已把 probabilistic forecasts 列为成熟发展方向之一。
7. **图学习动力学 + counterfactual intervention 在跨领域已经存在。** ABM-informed neural network、spatiotemporal causal GNN 等方法已能从经验数据学习动力学并执行 intervention/counterfactual simulation；因此 ECDS-TF 不可把该通用算法组合表述为首创。
8. **LLM 历史回测污染风险得到强证据支持。** 2025–2026 年研究显示 prompted knowledge cutoff 并不能可靠让 LLM“回到过去”，并出现专门的 ex-ante benchmark、claim-level leakage metric 和 leakage-adjusted backtesting 方法。
9. **Vulnerability Demand Pull 仍是目前最有潜力的专项 gap。** 本轮检索大量结果集中于 CVE 严重度预测、漏洞披露流程、风险管理和漏洞数量预测，暂未发现高度直接的“CVE/CWE/KEV 作为需求牵引状态，与论文/专利/GitHub共同用于防御技术预见”的方法论文。该结论仍为“未检出直接反例”，不是“证明不存在”。

### 方法贡献重新排序

当前优先级调整为：

1. **Vulnerability Demand Pull**：把 CVE/CWE/KEV 建模为安全技术研发/工程扩散的需求压力通道；
2. **STOV Role-aware Technology State**：四源不是拼接，而是不同演化机制状态；
3. **Learned Dynamics → Intervenable Technology Simulation**：在技术预见场景中把多源学习动力学转为可施加 shock 的 Monte Carlo 推演；
4. **Unified Historical Reconstruction Protocol**：多任务、多窗口、严格 temporal freeze 与 leakage audit；
5. **Calibration + Uncertainty + Scenario Sensitivity**：作为统一可信度评价协议；
6. **ECDS-TF + MAF-TF 双轨**：量化模型负责可回测概率，LLM Agent 只做真实未来的情景压力测试。
